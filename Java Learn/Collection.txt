Collection 
-----------
 -> Collection is framework that provids ready-made architecture 
    to store and manipulate group of object 
	
   -> Collections provide ready-made data structures (List, Set, Queue Map).
   -> Provide algorithms (sorting, searching)
   -> Provide type safety using Generics.

 Iterable
 ---------
     -> The Iterable interface in Java is the root interface of the Java Collection Framework
	 -> It is part of the java.lang package and is used to represent a collection of elements that can be iterated using a loop.
