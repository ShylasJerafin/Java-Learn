1. Queue interface 
  -----------------
  -> queue is sub interface of collection interface 
  -> it is follow FIFO principle (first In , first Out )
  Example: People standing in line — first person goes first.
  
Methods 
------------------  
add(e)	Insert element (exception if full)
remove()	Remove head (exception if empty)
element()	Get head (exception if empty)
offer(e)	Insert element (returns false if full)
poll()	Remove head (returns null if empty)
peek()	Get head (returns null if empty)

Common Implementations of Queue:
| Class           | Nature                   | Use case                      |
| --------------- | ------------------------ | ----------------------------- |
|  LinkedList     | Normal queue             | General queue operations      |
|  PriorityQueue  | Sorted based on priority | Highest/lowest priority first |
|  ArrayDeque     | Faster & re-sizable      | Recommended for queue/stack   |

LinkedList Queue 
-------------------
  -> Maintains Insertion Order
  -> Allows Duplicate Values 
  -> Allows null Value 
  -> FIFO principle 
  -> Dynamic size  
  -> No default capacity  
  
 PriorityQueue
 -------------------------
  -> does not maintains insertion Order
  -> Allows Duplicate values 
  -> does not Allows null values 
  -> follow priority based Ordering 
  -> Dynamic Size 
  -> default capacity 11      (defaultcapacity * 2) + 2;
  
 ArrayDeque
 -----------------------
   ->  Maintains Insertion Order
   ->  Allows Duplicate Values 
   ->  does not Allows null values 
   ->  follow FIFO principle    
   ->  Dynamic size 
   ->  default capacity  17    (defaultCapacity * 2)+2;

2.DeQueue Interface  
------------------------  
Deque ( Double Ended Queue) is a resizable array-based  and LinkedList-based 
implementation of the Deque interface.

It can be used as:
Queue -> FIFO (First In, First Out)
Stack -> LIFO (Last In, First Out)

It is faster than Stack and LinkedList for stack/queue operations.
Introduced in Java 1.6
Present in java.util package
No capacity limit (grows automatically)
	
Dequeue Methods 
----------
	addFist();
	addLast();
	Offerfirst();
	OfferLast();
	removeFirst(); 
	removeLast();
	pollFirst();
	pollLast();
	getFirst();
	getLast();
	PeekFirst();
	peekLast();
	
--->  Queue 
	add(); 
	offer();
