1.Why Java is called "Write Once, Run Anywhere"
 - The bytecode produced by the compiler is platform-independent. As long as a computer has a compatible JVM installed, the same .class file can run on different operating systems like Windows, macOS, or Linux without recompiling.

Java code works in several steps:
1. You write the Java program
You create a file with a .java extension.
Ex:

public class Hello {
  public static void main(String[] args) {
      System.out.println("Hello, World!");
  }
}
2. The Java compiler compiles the code
The Java compiler (javac) translates the source code into bytecode.
Command: javac Hello.java
This creates a file named: Hello.class

3.The JVM runs the bytecode
The Java Virtual Machine (JVM) reads the .class file and converts the bytecode into machine code that your computer's processor can execute.
Command: java Hello
Output: Hello, World!

What is Java, and what are its key features?
 - Java is a high-level, class-based, object-oriented programming language and a platform designed to develop applications that can run across different operating systems.
 - Java was originally developed by Sun Microsystems and is now maintained by Oracle and the Java community.
 - Java source code is compiled into bytecode, and that bytecode can run on any operating system that has a compatible JVM.

Why is Java called platform independent?
 - Java is platform independent because the compiled Java bytecode can run on different platforms through platform-specific JVM implementations.
 - Java bytecode is platform independent, while the JVM is platform dependent.

 Is JVM platform independent?
 - No, the JVM itself is platform dependent. We have different JVM implementations for different operating systems and hardware architectures. 
 - Java achieves platform independence because the bytecode generated by the Java compiler is platform-neutral, and each platform-specific JVM executes that same bytecode.

Is Java completely object-oriented?
 - Java is object-oriented, but it is not a pure object-oriented language because it supports primitive data types such as int, char, boolean and double, which are not objects.
 - Because in a purely object-oriented language, everything would be treated as an object. Java has primitives for performance and simplicity.

What exactly does the Java compiler do?
 - The Java compiler, javac, compiles Java source code into platform-independent JVM bytecode stored in .class files. 
 - At runtime, the JVM loads, verifies and executes that bytecode. Depending on the JVM and execution profile, bytecode may be interpreted and/or compiled into 
native machine code by the JIT compiler.

Compiler vs Interpreter:
 - A compiler translates the program before execution.
 - An interpreter executes instructions during runtime, generally processing them step by step rather than producing a complete native executable ahead of time.
 - The Java compiler first converts: .java → .class
 - Then the JVM can execute the bytecode using an interpreter and/or JIT compiler.
