ArrayList:
 - subclass of List Interface
 - can store both homo and heterogeneous type of objects.
 - Data structure is growable in size
 - Default capacity = 10
 - It also implements from RandomAccess, Cloneable, Serializable.
 - Objects are stored in continuous memory.
 - If our frequent operation is insertion and deletion, ArrayList is not recommended to use.
 - Because it follows shift wise moving -> so slower the performance
 - If our frequent operation is fetching datas from the object.
 - Duplicate values and null elemets are allowed.
 - Maintains insertion order
