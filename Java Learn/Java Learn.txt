Instance Variable
1.if the value of the variable varied from Obj to Obj, then such type of var are known as instance var
2.Instance var will be created at the time of obj creation and destroyed at the time of obj destruction
3.Scope of Inst var is the scope of the object
4.We cannot access inst var directly into static methods but can access by using obj reference.
5.Ins var also known as Attributes or Obj lvl variables
6.Default value is provided by JVM. if we are not performing initialization.

3.we can access the static variable using class name.
