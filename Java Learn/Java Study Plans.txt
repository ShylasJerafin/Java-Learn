9.Interface
 - In interface all the variables declared in final static variables by default and methods are public abstract by default.
 - Multiple Inheritance can be achieved with interfaces, because the class can implement multiple interfaces.
 - The class which is implementing the interface, must define all the methods of interface.
 - We cannot create object for interface.
